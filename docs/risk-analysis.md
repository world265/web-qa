# Risk analysis

| ID | Риск | Impact | Priority |
|---|---|---|---|
| R-01 | Потеря или откат прогресса | Critical | P0 |
| R-02 | Покупка оплачена, но содержимое не начислено | Critical | P0 |
| R-03 | Двойное списание или двойное начисление | Critical | P0 |
| R-04 | Награда события не начислена | High | P1 |
| R-05 | Награда за рекламу не начислена | High | P1 |
| R-06 | Игрок не может продолжить из-за дефицита обязательного ресурса | High | P1 |
| R-07 | Merge создаёт неправильное количество предметов | High | P1 |
| R-08 | Прогресс загружается не для того аккаунта | Critical | P0 |
| R-09 | События недоступны из-за проблем с панелью | Medium/High | P1 |
| R-10 | Ложный индикатор действия вводит игрока в заблуждение | Medium | P2 |

## Приоритет регрессии

### P0

- запуск и загрузка прогресса;
- сохранение после игровых действий;
- покупка и начисление;
- отсутствие двойных операций;
- корректная загрузка аккаунта.

### P1

- merge;
- задания и события;
- рекламные награды;
- ресурсы;
- строительство.

### P2

- уведомления;
- расположение элементов;
- персонализация;
- дополнительные UX-улучшения.
