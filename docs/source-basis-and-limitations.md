# Основа проекта и ограничения

## Источник

Проект построен на основе выполненного тестового задания по браузерной игре. В задании были представлены:

- две найденные проблемы с интерфейсом и удобством использования;
- два предложения по улучшению;
- ответы на двенадцать сообщений игроков;
- наборы уточняющих вопросов для шести типов обращений.

## Что считается подтверждённым

Подтверждёнными считаются только функции и ситуации, прямо упомянутые в исходном задании или видимые на приложенных скриншотах:

- игровая карта с объектами;
- merge-механика;
- ресурсы и премиальная валюта;
- задания, события и награды;
- временные помощники;
- реклама за награду;
- покупки;
- профиль игрока;
- синхронизация прогресса через аккаунт Яндекса;
- Player ID;
- браузерная версия игры.

## Что является аналитическим выводом

Следующие элементы репозитория являются профессиональной переработкой исходного материала:

- классификация функциональных областей;
- модель рисков;
- тестовая стратегия;
- предлагаемый регрессионный чек-лист;
- severity дефектов;
- условия выпуска и рекомендации.

Они не выдаются за внутренние требования продукта или фактически выполненное коммерческое тестирование.

## Ограничения исследования

Из исходного задания известна только ОС Windows 11. Не указаны:

- браузер и его версия;
- разрешение экрана и масштаб браузера;
- версия игры и номер сборки;
- тип аккаунта;
- состояние игрового прогресса;
- скорость соединения;
- серверное окружение;
- точные шаги подготовки данных для каждого дефекта.

Поэтому перед повторной проверкой дефектов необходимо уточнить окружение и предусловия.

## Этические ограничения

При проверке production-игры нельзя:

- создавать нагрузку на сервер;
- использовать реальные платёжные данные;
- пытаться получить доступ к чужому прогрессу;
- обходить ограничения рекламы и покупок;
- публиковать Player ID, чеки или персональные данные игроков;
- выдавать предложения по улучшению за подтверждённые дефекты.
