# IMP-001: Свободное изменение имени игрока

## Тип

Product improvement / profile personalization.

## Наблюдение

Игроки хотят использовать собственный nickname вместо автоматически назначенного имени или имени, связанного с внешним аккаунтом.

## Почему это не bug

Исходный материал не содержит требования, что имя должно свободно редактироваться. Текущее ограничение может быть продуктовым решением.

## Предлагаемое решение

Добавить в профиль действие «Изменить имя» с:

- ограничением длины;
- нормализацией пробелов;
- фильтром недопустимой лексики;
- защитой от пустого имени;
- сообщением об успешном сохранении;
- ограничением частоты изменения при необходимости.

## Риски

- оскорбительные имена;
- impersonation;
- слишком длинный текст и поломка layout;
- несовпадение имени между устройствами;
- конфликт имени внешнего аккаунта и игрового профиля.

## Acceptance criteria — предложение

1. Пользователь может открыть редактирование из своего профиля.
2. Валидное имя сохраняется и отображается после повторного входа.
3. Невалидное имя отклоняется с понятным сообщением.
4. Изменение не влияет на Player ID и прогресс.
5. Новое имя синхронизируется между устройствами.
