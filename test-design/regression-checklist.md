# Regression checklist

## 1. Запуск и прогресс

- [ ] Игра открывается и загружает карту.
- [ ] Загружается ожидаемый Player ID.
- [ ] После refresh прогресс не откатывается.
- [ ] После повторного входа сохраняются последние действия.
- [ ] Краткий разрыв соединения не приводит к потере состояния.

## 2. Merge

- [ ] 3 одинаковых предмета объединяются по правилам игры.
- [ ] 5 одинаковых предметов дают предусмотренный результат.
- [ ] 10 предметов корректно обрабатываются как две группы по 5, если это правило цепочки.
- [ ] Исходные предметы списываются один раз.
- [ ] Новый предмет появляется в корректной клетке.
- [ ] Разные предметы не объединяются.
- [ ] Быстрые повторные действия не дублируют результат.
- [ ] Merge на краю или заполненной карте не приводит к потере предмета.
- [ ] Liquid Rainbow расходуется корректно.

## 3. Задания и уведомления

- [ ] Прогресс задания меняется после целевого действия.
- [ ] Индикатор появляется только при доступном действии.
- [ ] После получения награды индикатор исчезает.
- [ ] Повторное открытие окна не выдаёт награду второй раз.

## 4. События

- [ ] Все активные события доступны из интерфейса.
- [ ] Иконки не обрезаны.
- [ ] При переполнении панели есть способ открыть остальные события.
- [ ] Время окончания отображается корректно.
- [ ] Награда события начисляется один раз.
- [ ] Разрыв соединения во время получения награды не создаёт двойное начисление.

## 5. Ресурсы

- [ ] Gems корректно начисляются и списываются.
- [ ] Повторный клик не выполняет двойную трату.
- [ ] Нельзя потратить больше доступного баланса.
- [ ] После перезапуска баланс сохраняется.
- [ ] Есть доступный путь получения обязательных ресурсов для продолжения прогресса.

## 6. Genie и строительство

- [ ] Genie запускает допустимую строительную задачу.
- [ ] Время действия рассчитывается корректно.
- [ ] Перезапуск игры не сбрасывает активную задачу.
- [ ] Один и тот же помощник не используется сверх правил игры.

## 7. Реклама за награду

- [ ] Полный просмотр начисляет награду один раз.
- [ ] Раннее закрытие обрабатывается согласно правилам.
- [ ] Переход во внешний магазин и возврат не ломают состояние игры.
- [ ] Сбой рекламы не приводит к двойной награде.
- [ ] Награда соответствует месту запуска рекламы.

## 8. Покупки

- [ ] Успешная покупка начисляет правильное содержимое.
- [ ] Сумма и валюта соответствуют выбранному предложению.
- [ ] Отмена не начисляет содержимое.
- [ ] Ошибка платежа не отображается как успешная покупка.
- [ ] Повторный клик не создаёт две операции.
- [ ] После временного сбоя покупку можно корректно проверить по Player ID и времени.

## 9. Аккаунт и синхронизация

- [ ] Один аккаунт загружает ожидаемый прогресс на разных устройствах.
- [ ] При смене аккаунта не отображается чужой прогресс.
- [ ] Logout не удаляет сохранённый прогресс.
- [ ] Очистка browser cache не уничтожает серверный прогресс, если он привязан к аккаунту.

## 10. UI

- [ ] Основные элементы полностью видны на типовом разрешении.
- [ ] Панель событий не обрезана.
- [ ] Боковая реклама не перекрывает игровые элементы.
- [ ] Текст и подсказки не выходят за границы окна.
