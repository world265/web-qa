# Предлагаемый регрессионный чек-лист

> Статус: проектируемое покрытие. Исходное тестовое задание не подтверждает фактическое выполнение всех проверок.

## 1. Запуск и прогресс

- [ ] Игра открывается в поддерживаемом браузере.
- [ ] После входа загружается ожидаемый Player ID.
- [ ] Загружается актуальная карта и уровень.
- [ ] После обновления страницы прогресс не откатывается.
- [ ] После закрытия и повторного открытия сохраняются последние действия.
- [ ] При кратком разрыве соединения не создаётся частичное состояние.
- [ ] Ошибка загрузки сообщает игроку, что произошло и что делать.

## 2. Merge

- [ ] Три одинаковых предмета объединяются по правилам игры.
- [ ] Пять одинаковых предметов дают предусмотренный результат.
- [ ] Десять предметов обрабатываются как две группы по пять, если таково правило.
- [ ] Исходные предметы списываются ровно один раз.
- [ ] Новый предмет появляется в корректной клетке.
- [ ] Разные предметы не объединяются.
- [ ] Недопустимая позиция визуально отличается от допустимой.
- [ ] Диагональное размещение обрабатывается последовательно.
- [ ] Быстрые повторные перемещения не дублируют результат.
- [ ] Merge у края карты не приводит к потере предмета.
- [ ] Merge при переполненной карте имеет понятный результат.
- [ ] Liquid Rainbow расходуется один раз и заменяет допустимый предмет.

## 3. Задания и уведомления

- [ ] Прогресс задания меняется после целевого действия.
- [ ] Восклицательный знак появляется только при доступном действии.
- [ ] После получения награды индикатор исчезает.
- [ ] Недоступное действие не помечено как доступное.
- [ ] Несколько доступных действий отображаются однозначно.
- [ ] Повторное открытие окна не начисляет награду второй раз.

## 4. События

- [ ] Все активные события доступны из интерфейса.
- [ ] Иконки не обрезаны на поддерживаемых разрешениях.
- [ ] При переполнении панели есть прокрутка или отдельный список.
- [ ] Условия и время окончания события отображаются.
- [ ] Награда этапа начисляется один раз.
- [ ] Финальная награда доступна после выполнения условий.
- [ ] При завершении события во время открытого окна состояние обновляется.
- [ ] Разрыв соединения при claim не приводит к потере или двойной награде.

## 5. Ресурсы и траты

- [ ] Баланс gems корректно увеличивается и уменьшается.
- [ ] Значительная трата требует подтверждения, если это предусмотрено UX.
- [ ] Повторный клик не выполняет двойную трату.
- [ ] Нельзя потратить больше доступного баланса.
- [ ] После перезагрузки баланс совпадает с последней подтверждённой операцией.
- [ ] Источники gem fragments доступны в соответствии с прогрессом.
- [ ] Игрок не попадает в состояние без возможного дальнейшего действия.

## 6. Genie и строительство

- [ ] Genie доступен в предусмотренном состоянии.
- [ ] Genie запускает допустимую строительную задачу.
- [ ] Время действия рассчитывается корректно.
- [ ] Один Genie не используется одновременно сверх правил.
- [ ] После окончания таймера поведение строительства корректно.
- [ ] Перезапуск игры не сбрасывает активную задачу.

## 7. Реклама за награду

- [ ] Полностью просмотренная реклама начисляет награду один раз.
- [ ] Раннее закрытие обрабатывается согласно правилам.
- [ ] Переход в магазин и возврат не теряет состояние.
- [ ] Зависание рекламы не списывает попытку без результата.
- [ ] Перезапуск во время рекламы не даёт двойную награду.
- [ ] Ошибка рекламной сети отображается понятным образом.
- [ ] Награда соответствует месту запуска рекламы.

## 8. Покупки

- [ ] Успешная покупка начисляет правильный набор.
- [ ] Сумма и валюта соответствуют выбранному предложению.
- [ ] Отмена не начисляет содержимое и не создаёт ложный успех.
- [ ] Ошибка платежа не создаёт покупку.
- [ ] Повторный клик не создаёт две операции.
- [ ] После списания и временного сбоя покупка может быть восстановлена.
- [ ] Чек и время позволяют найти операцию.
- [ ] Содержимое не начисляется на другой Player ID.

## 9. Аккаунт и синхронизация

- [ ] Один аккаунт Яндекса загружает один и тот же прогресс на разных устройствах.
- [ ] При смене аккаунта не отображается чужой прогресс.
- [ ] Старый и новый Player ID корректно связываются или различаются.
- [ ] Logout не удаляет серверный прогресс.
- [ ] Очистка cache не уничтожает привязанный прогресс.
- [ ] Конфликт двух устройств обрабатывается предсказуемо.
- [ ] После обновления игры авторизация и прогресс сохраняются.

## 10. UI и адаптивность

- [ ] Основные элементы полностью видны на 1366×768.
- [ ] Интерфейс работоспособен при масштабе 80%, 100% и 125%.
- [ ] Боковая рекламная панель не перекрывает игровые элементы.
- [ ] Панель событий имеет отступ от края.
- [ ] Интерактивные зоны соответствуют визуальным элементам.
- [ ] Подсказки не выходят за границы окна.
- [ ] Текст читаем и не обрезан.
